# Editorial Calendar

## WEEKLY SYSTEM

Target starting volume:

### Instagram

3–5 feed posts/week

### TikTok

3–5 videos/week

### Facebook

3–5 posts/week

### Pinterest

5–10 pins/week

Adjust based on available resources and performance.

---

# WEEKLY THEME MODEL

Each week should have a primary wellness theme.

Example:

## WEEK 1

Theme:

Sleep & Recovery

Monday:
Educational Reel

Tuesday:
Carousel

Wednesday:
Recipe

Thursday:
TikTok

Friday:
Facebook discussion

Saturday:
Product education

Sunday:
Pinterest evergreen content

# CONTENT PLANNING FIELDS

Every content item should record:

* Date
* Platform
* Pillar
* Topic
* Hook
* Format
* Caption
* CTA
* Destination URL
* Product/vendor
* Status
* Performance
