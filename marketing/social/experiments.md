# Marketing Experiments

## PURPOSE

LMG should continuously test and learn.

Never assume a strategy works simply because it sounds good.

---

# EXPERIMENT TEMPLATE

## Hypothesis

Example:

> Question-based hooks will generate higher watch time than statement-based hooks.

## Test

Create 5 videos using question hooks.

Create 5 videos using statement hooks.

Keep other variables reasonably similar.

## Measure

* 3-second retention
* Average watch time
* Completion
* Shares
* Saves
* Website clicks

## Result

Record findings.

## Decision

Choose:

* Keep
* Modify
* Stop
* Test again

---

# TEST CATEGORIES

## CONTENT

* Topic
* Format

## CREATIVE

* Hook

## CONVERSION

Tests should produce useful learning.
